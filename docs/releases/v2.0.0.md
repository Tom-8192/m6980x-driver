First Rust release of the M6980X Configuration Tool, an unofficial replacement for Gigabyte's "GHOST Macro Engine"
for the **Gigabyte GHOST M6980X** mouse. No installation and no runtime needed.

### Downloads

| File | Contents |
|---|---|
| `m6980x-configtool-2.0.0-windows-x64.zip` | `m6980x_configtool.exe` (command line), `m6980x_configtool_gui.exe` (GUI) |
| `m6980x-configtool-2.0.0-linux-x64.tar.gz` | `m6980x_configtool`, `m6980x_configtool_gui`, udev rule `70-m6980x-configtool.rules` |

### Features

- Profile, LED colour per profile (27 colours), DPI per stage (separate X/Y, 90–6030), report rate, persistent save
- Button assignment: 46 functions, macros, built-in default
- Macros: editor, 3 modes, mouse wheel, consumer keys, pictures 1–100; import/export of the original's `.ini` files
- Full backup/restore (JSON), memory dump/import incl. the original's `.meb` format
- Every write is read back; packets are byte-identical to the Python prototype 1.1 that was tested on the device
- New: cross-process lock, so the GUI and the command line can run at the same time

### Tested

- **Windows:** read, write and restore tested on the mouse (memory byte-identical after restore), lock tested with GUI
  and command line in parallel.
- **Linux:** builds and passes all tests in CI, **not yet tested with the mouse**. Install the udev rule first
  (see README).

The user interface and command-line arguments are in German.
