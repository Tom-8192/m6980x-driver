The M6980X Configuration Tool gets the **scroll settings** of the original software. Unofficial replacement for
Gigabyte's "GHOST Macro Engine" for the **Gigabyte GHOST M6980X** mouse. No installation and no runtime needed.

### Downloads

| File | Contents |
|---|---|
| `m6980x-configtool-2.3.0-windows-x64.zip` | `m6980x_configtool.exe` (command line), `m6980x_configtool_gui.exe` (GUI) |
| `m6980x-configtool-2.3.0-linux-x64.tar.gz` | `m6980x_configtool`, `m6980x_configtool_gui`, udev rule `70-m6980x-configtool.rules` |

### New

- **Scrolling (Windows):** new card on the performance page and command `scroll`: vertical speed (lines per wheel
  notch, like the original) and horizontal speed (characters per tilt step), 1–100, with a "Windows default" button.
  These are Windows settings for all programs, not stored in the mouse.
- **Tilt wheel mode:** the original's helper `Tilt.exe` switches the mouse into its own tilt mode at every start;
  then only Tilt.exe scrolls horizontally. The button **"Tilt wheel native"** (command `tilt-mode native`) switches
  back. Unplugging the mouse does the same. While Tilt.exe runs, the tool shows a note.
- **Warning while the original's `Macro.exe` runs:** it talks to the mouse over the same channel, and replies can get
  mixed up.

### Fixed

- Five command line messages showed placeholders like `%{profile}` instead of the values (`backup`, `rom-import`,
  `macro`, `macro-export`, `macro-import`). A new test checks every message in all languages.

### Unchanged

The packets sent to the mouse for all existing functions are byte-identical to 2.2.0 (parity tests against the
Python prototype).

### Tested

- **Windows:** `tilt-mode` switched on the device in both directions; scroll speed read and written. The new GUI card
  was checked with the simulated mouse.
- **Linux:** builds and passes all tests in CI, **not yet tested with the mouse**. Scroll speed and tilt mode are
  Windows only (on Linux the mouse always starts in native mode). Install the udev rule first (see README).
