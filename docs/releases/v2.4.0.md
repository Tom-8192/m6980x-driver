The M6980X Configuration Tool gets **its own macro icons**. Unofficial replacement for Gigabyte's "GHOST Macro
Engine" for the **Gigabyte GHOST M6980X** mouse. No installation and no runtime needed.

### Downloads

| File | Contents |
|---|---|
| `m6980x-configtool-2.4.0-windows-x64.zip` | `m6980x_configtool.exe` (command line), `m6980x_configtool_gui.exe` (GUI) |
| `m6980x-configtool-2.4.0-linux-x64.tar.gz` | `m6980x_configtool`, `m6980x_configtool_gui`, udev rule `70-m6980x-configtool.rules` |

### New

- **Own macro icons:** 40 new pictures (made with an image AI from the descriptions of the original's pictures, no
  Gigabyte images) for icons 1–40. Icons 41–100 are shown as a metal frame with a silver number.
- **"Choose icon…" dialog** in the macro editor: a grid with "no icon", the 40 pictures and the numbers 41–100. Hover
  shows the description, a double click applies. The editor shows a preview of the chosen icon.
- **Macro list:** a small icon in front of the name of every macro that has one.
- The icons are built into the program (about 135 KB, WebP).

### Changed

- **Horizontal scroll speed removed** (from 2.3.0): the Windows setting "characters per tilt step" is ignored by
  programs like Excel and Firefox, so the slider had no visible effect. `scroll` now only takes the lines per wheel
  notch (`scroll 3`). The "Tilt wheel native" button stays.

### Unchanged

The packets sent to the mouse are byte-identical to 2.3.0 (parity tests against the Python prototype). The icon
number stored in the mouse is the same as with the original software.

### Tested

- **Windows:** icon dialog, preview and macro list checked with the simulated mouse (`--fake`); choosing and saving an
  icon stores the right icon byte. **Not yet tested on the real mouse.**
- **Linux:** builds and passes all tests in CI, **not yet tested with the mouse**. Install the udev rule first (see
  README).
