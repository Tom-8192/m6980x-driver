The M6980X Configuration Tool gets a **completely redesigned GUI**. Unofficial replacement for Gigabyte's
"GHOST Macro Engine" for the **Gigabyte GHOST M6980X** mouse. No installation and no runtime needed.

### Downloads

| File | Contents |
|---|---|
| `m6980x-configtool-2.2.0-windows-x64.zip` | `m6980x_configtool.exe` (command line), `m6980x_configtool_gui.exe` (GUI) |
| `m6980x-configtool-2.2.0-linux-x64.tar.gz` | `m6980x_configtool`, `m6980x_configtool_gui`, udev rule `70-m6980x-configtool.rules` |

### New

- **New layout:** side bar with overview, buttons, lighting, DPI, performance, macros and backup; header with the
  connection state and the three profiles in their LED colours; dark and light theme.
- **Changes apply at once** – no more "Set" buttons. DPI values are written when the slider is released.
- **Buttons:** a drawn mouse – click a button on it (or in the list) and pick the new function from a searchable,
  grouped list.
- **Lighting:** colour presets as swatches plus off/medium/full per channel.
- **Macro editor:** step list (add, edit, reorder, delete), text view as before, and **recording** of keys, mouse
  buttons and the wheel with or without pauses.
- **Saving a macro** shows a clear progress bar and a confirmation, and is about 5 seconds faster: only the written
  slot and the name table are read back instead of the whole memory. A macro without a name is named after its slot
  ("Macro 3").
- Macro text knows more keys: `f13`–`f24`, the German punctuation keys (`ü`, `ö`, `ä`, `komma`, `punkt`, …) and
  `0xNN` for any key.

### Unchanged

The packets sent to the mouse for all existing functions are byte-identical to 2.1.0 (parity tests against the
Python prototype). Key names in macros still follow the German QWERTZ layout.

### Tested

- **Windows:** GUI checked with the simulated mouse and started on the device; recording and macro progress
  covered by tests.
- **Linux:** builds and passes all tests in CI, **not yet tested with the mouse**. Install the udev rule first
  (see README).
