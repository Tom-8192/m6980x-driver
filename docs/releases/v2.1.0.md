The M6980X Configuration Tool is now **multilingual**: English by default, German included, and further languages
can be added without code changes. Unofficial replacement for Gigabyte's "GHOST Macro Engine" for the
**Gigabyte GHOST M6980X** mouse. No installation and no runtime needed.

### Downloads

| File | Contents |
|---|---|
| `m6980x-configtool-2.1.0-windows-x64.zip` | `m6980x_configtool.exe` (command line), `m6980x_configtool_gui.exe` (GUI) |
| `m6980x-configtool-2.1.0-linux-x64.tar.gz` | `m6980x_configtool`, `m6980x_configtool_gui`, udev rule `70-m6980x-configtool.rules` |

### New

- **Languages:** English and German (with proper umlauts). The GUI has a language picker (top right, remembered);
  the command line takes `--lang en|de`. Without a choice, `M6980X_LANG` or the system language decides.
- **Input in every language:** `button 1 back copy` and `button 1 hinten kopieren` both work, as do macro texts like
  `tap ctrl+c, wait 100` and `tippe strg+c, warte 100` (also without umlauts, e.g. `drueck`).
- **More languages without code changes:** all texts are in `locales/<code>.yml`; copy `en.yml`, translate, rebuild.
  Tests check that every language file is complete.
- **GUI: "Link X and Y"** checkbox on the DPI tab – Y follows X, so each stage needs only one value.
- Command-line help now describes every argument.
- English option names `--temporary`, `--icon` and `macro-icon`; the old German names (`--temporaer`, `--bild`,
  `macro-bild`) still work.
- Code comments and documentation are in English (`docs/PROTOCOL.md`, `docs/HANDOVER.md`).

### Unchanged

The packets sent to the mouse are byte-identical to 2.0.0 (parity tests against the Python prototype).
Key names in macros still follow the German QWERTZ layout (y and z swapped compared to US).

### Tested

- **Windows:** all mouse functions were tested on the device with 2.0.0; 2.1.0 changes only texts and the GUI.
  The 2.1.0 GUI was smoke-tested in both languages with the simulated mouse.
- **Linux:** builds and passes all tests in CI, **not yet tested with the mouse**. Install the udev rule first
  (see README).
