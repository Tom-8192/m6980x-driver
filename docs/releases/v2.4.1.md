A small update to the GUI of the M6980X Configuration Tool. Unofficial replacement for Gigabyte's "GHOST Macro
Engine" for the **Gigabyte GHOST M6980X** mouse. No installation and no runtime needed.

### Downloads

| File | Contents |
|---|---|
| `m6980x-configtool-2.4.1-windows-x64.zip` | `m6980x_configtool.exe` (command line), `m6980x_configtool_gui.exe` (GUI) |
| `m6980x-configtool-2.4.1-linux-x64.tar.gz` | `m6980x_configtool`, `m6980x_configtool_gui`, udev rule `70-m6980x-configtool.rules` |

### Changed

- **Redrawn mouse:** the mouse picture in the GUI now follows the shape of the real M6980X (top view, still drawn
  by the program, no product photos or logos).
- **Header:** the GUI header shows "GHOST M6980X" instead of "G3", the name the mouse reports about itself. The
  "Device" tile still shows the reported name.
- The 512 px sources of the macro icons are now part of the repository (`assets/icons/source/`), so the icons can
  be rebuilt with `py -3 assets/icons/make_icons.py`.

### Unchanged

The packets sent to the mouse are byte-identical to 2.4.0 (parity tests against the Python prototype).

### Tested

- **Windows:** new mouse picture and header checked with the simulated mouse (`--fake`).
- **Linux:** builds and passes all tests in CI, **not yet tested with the mouse**. Install the udev rule first (see
  README).
